# 新 V 级里程碑 `grade_milestone`

## 情绪目标

把真实等级变化表达为一个可配置的三段进阶，例如 `V1 → V2 → V3`。等级字符串只由 Flutter 的真实数据绘制，动画本身不硬编码业务值，也不制造额外货币或概率奖励。

## 镜头与时间

- 规格：`512×512`、`60fps`、`op=66`、透明、一次播放。
- `f0–f18`：黑猫从进阶轨迹上方探出并安静落稳；第一枚葡萄色等级岩点从 `.76 → 1` 出现，不回弹。
- `f10–f27`：第一段箭头由左下向中上画出，向日葵色中间等级岩点随后从 `.82 → 1` 出现。
- `f23–f47`：第二段箭头由中上向右下画出；最后一枚珊瑚等级岩点 `scale .70 → 1.08 → 1`，是全场唯一强回弹元素。
- `f34–f52`：黑猫双爪向外打开回应最新等级；最新等级旁的星与碎片在 `f59` 前全部淡出。
- `f53–f65`：黑猫、三段等级与两枚箭头完全静止，形成稳定终态。

## 动态等级安全区

- 三个无文字奶油色内区尺寸均为 `74×58`，画布中心依次为 `(136,314)`、`(256,286)`、`(376,314)`。
- 对应归一化中心为 `(0.266,0.613)`、`(0.500,0.559)`、`(0.734,0.613)`；Flutter 叠字应使用同一组坐标。
- 动画 JSON 不包含 `V1/V2/V3` 或用户数据。无本月数据时由 Flutter 使用 `V1/V2/V3`；有数据时由 Flutter 提供最近的有效等级序列。

## 产品接入

- 只在后端返回 `milestone` 时用于正式结果页；实验室可用默认序列验证排版，其他完攀使用 `send_success`。
- 正式页面在三个安全区叠加真实的最近等级序列；缺少可用本月数据时才回退 `V1/V2/V3`。
- 建议在最后一枚等级岩点落下时配一次重触觉和现有 `milestone.wav`。
