# 线路发布成功 `route_published`

## 情绪目标

让黑猫亲手用笔完成一条记录路径，再出现明确的薄荷色勾章。实验室将它呈现为“记录成功”，正式线路发布页仍可把这条路径理解为已经画完并保存的线路图。

## 镜头与时间

- 规格：`512×512`、`60fps`、`op=60`、透明、一次播放。
- `f0–f18`：记录纸从下方淡入并落稳，黑猫从纸后探出，瞳孔略向左下看向路径；纸张只做 `.90 → 1` 的无回弹进入。
- `f6–f9`：黑猫的独立前爪先握住葡萄色画笔并显现；在路径开始增长前，笔尖已经落在第一枚岩点位置。
- `f8–f34`：画笔尖依次经过路径的每个转折点，珊瑚路径的 trim 与笔尖位置使用同一组关键帧同步增长；三枚岩点在笔尖到达时依次出现，形成清楚的“猫亲手画完了”。
- `f34–f43`：画笔抬到黑猫身边并停住，完整路径保持可见。
- `f36–f52`：薄荷色圆形勾章在记录纸右下角 `.70 → 1.08 → 1`，白色勾线随后画完；勾章是全场唯一强回弹元素。
- `f56–f59`：黑猫、画笔、完整记录与勾章完全静止；唯一庆祝星已淡出。

## 产品接入

- 在发布 API 成功后显示全屏结果动效，动画完成后再显出“完成并返回”按钮。
- 线路名、岩馆和视频审核状态由 Flutter 显示。
- 实验室标签可显示“记录成功”，但运行时仍只在真实保存/发布成功后使用；失败和视频待审继续保留明确文字。
- 使用独立 `route-published.wav`；画笔绘制过程保持安静，薄荷勾章出现时在 `683ms` 只播放选定的 D `E5 → C6` 轻快上扬双音。
- 减少动效或静态兜底时直接定位至 `683ms` 的同一 D 双音；声音跟随结果出现，不跟随“完成并返回”按钮出现。
