# 首页本周新线

目前按产品要求暂用三张成都岩馆卡片：香蕉攀岩、丘山攀岩、熊猫攀岩。卡片可横向滑动，不显示“示例数据”标记；首页选择全国或成都时显示，选择其他城市时隐藏。

- 香蕉攀岩进入凯德天府店详情，岩馆 ID 为 `71330197-04ac-4d15-8db6-b35a490088d4`。
- 丘山攀岩进入 CyPARK 店详情，岩馆 ID 为 `fe86c13b-9f60-4f20-90fd-acdbc5a37ccb`。
- 熊猫攀岩进入成都品牌门店列表，品牌 ID 为 `b0104aad-3abe-4830-9f53-3d85c881b6be`，由用户选择具体门店。

模拟模式不请求本周新线接口，也不向服务器写入模拟数据。卡片只展示岩馆名称、所在城市、已确认的门店和“查看岩馆”入口。

数据集中在 `flutter_app/lib/features/gyms/application/weekly_route_preview_data.dart`。当前 `USE_WEEKLY_ROUTE_MOCKS` 默认为 `true`；后续数据和接口上线后，改为 `false`，或用 `--dart-define=USE_WEEKLY_ROUTE_MOCKS=false` 启动/构建。

关闭模拟模式后，首页从 `GET /api/routes/weekly?city=上海&limit=10` 获取真实线路，卡片直接进入对应线路详情。

## 数据口径

- 数据来源是用户发布线路或后台录入的 `routes`，不自动同步第三方岩馆的换线信息。
- “本周”从北京时间周一 00:00 到接口接收请求时刻，按 `routes.created_at` 筛选，并要求 `published=true`。
- 这是本周新增收录的已发布线路，不代表岩馆实际施工或换线日期；完攀时间、视频上传时间和换线周期起始日期均不参与筛选。
- 按新增时间倒序，同一时间按线路 ID 倒序；首页显示最新 10 条，可横向滑动。
- `city` 跟随首页定位或手动选择。全国时省略，空白也按全国处理。
- `limit` 默认 10，可传 1–20 的整数。

## 接口

响应包含 `items`、`weekStart`、`weekEnd`；这里的 `weekEnd` 表示本次查询截止时刻。

每条数据包含线路本身字段，以及 `gym_name`、`gym_address`、`gym_city`。`created_at` 和时间窗口采用带时区的 ISO 时间。

游客可以读取；携带无效或过期的登录凭证仍返回 401。没有新线时返回空 `items`，不会用岩馆总线路数填充。

## 刷新与上线

真实数据模式下，切换城市、下拉刷新、发布线路返回和查看线路返回时会重新获取。新线请求与岩馆目录独立；空数据、加载中或失败时隐藏该区域，下拉刷新可重试。

切回真实数据前需要先发布包含该路由的后端。旧后端会把 `weekly` 当作线路 ID，返回参数错误；客户端会隐藏新线区域。

线上数据不足时，先通过“发布线路”选择实际门店、填写线路与照片完成录入。只有本周录入、已发布且属于所选城市的线路会进入这个区域。

定向验证见 `server/test/weekly-routes*.test.ts`、`flutter_app/test/weekly_routes_test.dart`；数据库测试只能使用隔离的本地测试库。
