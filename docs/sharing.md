# 线路与攀岩月记分享

## 用户操作

Flutter 线路详情右上角「分享线路」打开链接分享弹层，支持系统分享、复制链接和浏览器预览。

「我的 → 攀岩日历」只保留右上角分享入口。点击后直接在当前屏幕显示月度图片预览，包含已选月份的真实成绩、攀岩日历和完攀日记品牌；空月最高难度显示 `--`。日历和图片第四项均显示「点数」，按现有完攀积分计算：每条 `10 + V 级 × 5`，闪攀额外 `5` 点，按所选月的 `byGrade` 与 `summary.flashes` 合计，不含排行点赞奖励。点击「分享给朋友」将同一张预览导出为 1080 × 1680 PNG，并打开系统分享面板，选择微信或其他已安装应用。取消、失败可以重试；关闭弹窗会阻止尚未完成的图片生成调起分享。弹窗不再显示链接说明、复制／跳转预览或停止分享按钮。

月度图片使用当前日历已经加载的数据，是发送时的静态记录。打开预览和发送图片均不会查询、创建或撤回公开链接，也不会公开昵称、头像、具体岩馆或记录媒体。历史月度链接接口与网页保持兼容，仍按原合同提供实时汇总、撤回与账号删除处理；新图片流程不再使用它们。
线路链接及历史月报链接的接收者无需登录即可浏览网站详情，iOS 下载转 App Store `6806735896`，Android 转官网现有 `/#download`。不会自动下载或自动跳转遮挡内容；微信内不能下载时显示在浏览器打开的指引。网页提供条目级标题和摘要元数据，微信聊天富卡片效果需真机验证，不承诺仅凭 Open Graph 标签获得微信富卡片。

## 服务合同

| 方法与路径（`/api` 前缀） | 权限与结果 |
| --- | --- |
| `GET /shares/routes/:id` | 匿名读取 published 线路白名单；提供坏 JWT 仍返回 401 |
| `GET /shares/monthly?month=YYYY-MM` | 本人查询 `{month, token}`，未开启时 token 为 null |
| `POST /shares/monthly` `{month}` | 本人创建／复用链接；未来月份拒绝；随机 32 字节 base64url token |
| `GET /shares/monthly/:token` | 匿名读取有效链接的实时汇总；无效或撤回 404 |
| `DELETE /shares/monthly/:token` | 仅本人撤回；重复撤回安全；账号删除级联移除分享 |

新表 `monthly_record_shares` 由现有 schema migration 幂等建立，唯一键 `(user_id, month)`。公开 GET 每 IP 每分钟 600 次，避免官网服务端请求共用出口 IP 时小规模集中分享被误限流；创建／撤回有独立较低限额。官网通过服务端 fetch 请求固定生产 API，无浏览器 CORS 变更、无私密凭据转发。API 与网页均设置 no-store/noindex/no-referrer。

1. 后端 `npm --prefix server run check`、`test`、`build`；`test:e2e` 只对独立本机测试库运行，新套件覆盖上海月份边界、可见性、并发复用、撤回、换 token、删除账号与 schema 重跑。
2. Flutter 分享 repository/service/sheet/calendar 专项测试，包含 iPad 原生分享锚点、320px 宽和放大字体、切月／关闭竞态、网络失败与重试。
3. 官网 `node --experimental-strip-types --test scripts/test-share.mjs scripts/test-download.mjs`、TypeScript 与生产构建。
4. 已进行独立数据库 → API → 网站 SSR 联调：线路与月报内容、条目元数据、下载地址、禁缓存头、撤回旧链接 404 和重建后旧链接仍 404。
5. 生产先按现有备份／迁移／部署流程上线 API，验证 `/health`、`/ready` 和分享路由；再发布同一个 Sites 项目的新官网版本。最后发布新版 Flutter App；旧 App/旧 APK 不会自动获得 Flutter 代码更新。

分享官网生产来源为 `https://wanpan-diary.racing-crumb-9418.chatgpt.site`，Flutter 可通过 `SHARE_BASE_URL` 指定 HTTPS origin。网站开发联调的 `SHARE_API_BASE_URL` 只在开发服务器有效，不会进入生产构建。
